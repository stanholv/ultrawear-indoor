Ultrawear Indoor — logo files
=============================

SVG (vector, scales to any size — use these on the web and for print)
  ultrawear-indoor-color.svg   primary, works on light backgrounds
  ultrawear-indoor-dark.svg    slightly deeper palette for dark backgrounds
  ultrawear-indoor-mono.svg    single-colour light, e.g. on photos
  ultrawear-indoor-light.svg   outline version for light/one-colour print

PNG (raster, transparent background)
  ultrawear-indoor-1024.png        general use, social avatars
  ultrawear-indoor-256.png         app / web
  ultrawear-indoor-favicon-64.png  browser tab, small UI
  ultrawear-indoor-dark-1024.png   on dark background

Colours
  #B31F2A  stripe red
  #4E1519  ring maroon
  #120C0B  outer rim
  #1B1412  stripe dark
  #DCCFB8  lettering bone
  #C3AB86  frame tan

Type
  Ring lettering and wordmark: Oswald 600 (Google Fonts).
  The SVGs load Oswald from Google Fonts, so lettering renders correctly in
  browsers. In Illustrator or Figma, install Oswald first, or use the PNGs.

Minimum size
  Do not use the full crest below 44 px; below that the ring text closes up.
  Use the favicon PNG or crop to the diamond frame instead.
